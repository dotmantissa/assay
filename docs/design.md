# Assay design tokens

Seed: 1792831722308016215. Independent rolls: 0, 3, 2, 0, 4.

1. Colour hierarchy: yellow workspace (#EDE734), black ink (#000000), white evidence surfaces (#FFFFFF). Dark mode reverses the workspace to black and reserves yellow for emphasis. This feels like a mark of certification rather than a financial dashboard.
2. Layout: dashboard first split pane. A narrow persistent navigation spine, a wide public ledger, and a contextual evidence rail put comparisons and proof within one glance.
3. Type: Fraunces display serif for consequential statements and benchmark names, DM Sans for reading and controls. Tabular numerals carry measured scores. The contrast recalls an assay office certificate without imitating a historical document.
4. Motion: one orchestrated opening sequence built around the mark and ledger reveal. Other transitions communicate state changes. Respect reduced motion. No repeated section entrance effects or hovering cards.
5. Structural device: the assay fingerprint, a grid of real sampled outcomes. The pattern shows where a score comes from and why agreement about mistakes matters. An empty fingerprint explains that no verdict exists yet.

The layout avoids a centered hero and repeated feature cards. No tracked uppercase eyebrows, em dash labels, decorative numbered steps, automatic arrows, or interchangeable rounded shadowed cards. Navigation uses Lucide icons. The logo is a geometric crucible and letter A, rendered as SVG and reused as the favicon.
